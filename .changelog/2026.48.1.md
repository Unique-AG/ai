## 2026.48.1 - 2026-11-26

### Orchestrator
#### Added
- AUDIENCE_USER: The debug information of each turn now has a `skill_loading` entry with how many skills were listed, loaded, taken from the cache, downloaded, failed, and left out because they were not loaded in time. Before, these counts were only in the service logs.
#### Fixed
- AUDIENCE_USER: Spaces with many skills lose far fewer skills to download timeouts. Before, all skill files were downloaded at once, and a download that timed out silently dropped that skill for the turn. A skill whose download still fails after the retry, or whose file cannot be used, is still left out of that turn. Downloads now share a limit of 10 at a time across all turns of a worker process, wait up to 20 seconds and are retried once. A turn waits at most 30 seconds for its skills; a skill not loaded by then is left out of that turn. Once per turn the orchestrator asks the platform, waiting up to 5 seconds, which skills the user can read in the space and when each skill file last changed. A skill on that list is parsed once and then kept in memory, so later turns download only new or edited skills. A skill that is not on the list is downloaded as the user on every turn. The in-memory part needs a platform version that serves `GET /space/{spaceId}/skills`; on an older platform every skill is downloaded, with the new limit and retry.

### SDK
#### Added
- AUDIENCE_DEVELOPER: `unique_sdk.Space.get_skills` and `get_skills_async` return the skills of a space that the calling user can read, each with the content ID, folder ID, name and last-modified time of its skill file. They need a platform version that serves `GET /space/{spaceId}/skills`.

### Tools
#### Changed
- AUDIENCE_ADMIN: The skill list in Unique AI chat now grows with the model's context window. Its budget is 2% of the input window, and never less than the previous fixed 8,000 characters. Spaces on large-window models keep longer skill descriptions, so the model can tell the skills apart. Admins can change the share per space in the Skills settings ("Skill List Budget"). The unused "Skill Budget Context Percent" setting is no longer shown.
