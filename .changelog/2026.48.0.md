## 2026.48.0 - 2026-11-20

### Connectors
#### Security
- AUDIENCE_OPERATOR: Search proxy image patches four published HIGH container vulnerabilities and picks up the latest OS security updates on every release build.
- AUDIENCE_OPERATOR: Search proxy image updates soupsieve to 4.1, which fixes a published HIGH denial of service in CSS selector matching.

### Orchestrator
#### Added
- AUDIENCE_DEVELOPER: `build_unique_ai` takes keyword-only `evaluation_factories`, each building one evaluation per turn from an `EvaluationBuildContext` (chat service and reference manager). A factory evaluation named `hallucination` replaces the built-in hallucination check, which is then not created. Without factories nothing changes.

### Postprocessors
#### Fixed
- AUDIENCE_ADMIN: Follow-up questions now apply the `additionalLlmOptions` set in `followUpQuestionsConfig` (e.g. `reasoning_effort: none`) to every LLM call, including language detection. Previously these options were ignored and the model defaults were used.

### SDK
#### Added
- AUDIENCE_DEVELOPER: `unique-cli search` takes further queries with `-q` and runs up to 8 in one call concurrently. A chunk found by several queries is shown once, and the output stops at about 100,000 tokens, taking the best results of every query first. A single query behaves as before. In an agent workspace, `unique-cli search` refuses more than 100 calls per minute; `UNIQUE_CLI_SEARCH_MAX_CALLS_PER_MINUTE` changes the cap.
- AUDIENCE_DEVELOPER: unique-cli read records each document it returns in .unique/read-refs.jsonl, so the generated-file check can judge files against the documents the agent read in full.
- AUDIENCE_DEVELOPER: unique-cli agentic-table delete-row permanently deletes one Agentic Table content row by its row id.
- AUDIENCE_DEVELOPER: `unique_sdk.ProjectMemory` reads, writes and deletes the memory of a project the user owns (`retrieve`, `modify`, `delete` and their `_async` variants). `modify` takes the markdown `document` and an optional `state` for the project memory job; without `state` the stored state is kept. Requires the Projects feature flag `FEATURE_FLAG_ENABLE_PROJECTS_UN_28332` for the user.
#### Fixed
- AUDIENCE_DEVELOPER: The bundled `unique-cli-uploaded-search` skill and the empty `unique-cli uploaded-search` reply now describe the documents attached to the current message, in regular chats as well as Agentic Table rows, and point to knowledge-base search only where a space has it.
- AUDIENCE_DEVELOPER: The `unique-cli-mcp` skill now says `[mcpsourceN]` numbers are chat-wide. A number from an earlier turn still resolves, and re-fetching the same item in a later turn can assign a new number. The skill no longer says earlier-turn numbers are stale. It also teaches title-and-link markers (`[mcpsourceN;title;URL]`) and citing what action tools created.
- AUDIENCE_DEVELOPER: `unique-cli search` with several queries now shows the results of every query. Against a real backend each query printed "Results left out: output budget reached." because the search response was not read as a list. A single query was not affected.

### Tools
#### Changed
- AUDIENCE_DEVELOPER: The internal search and web search evaluation check list descriptions say the hallucination entry is obsolete when the space has the Hallucination check setting under Services > Evaluation Config.

### Toolkit
#### Added
- AUDIENCE_DEVELOPER: Chat and Agentic Table events expose the chat UI language as `payload.ui_language` (`None` when the platform does not send it). `ui_language(event)` from `unique_toolkit.app.ui_language` returns it as a `UiLanguage` (`en`, `de`, `fr`), falling back to English.
- AUDIENCE_DEVELOPER: Experimental Activity Records event model, a Pydantic port of the CloudEvents schema that the Activity Records service validates.
- AUDIENCE_DEVELOPER: Experimental size limits and row preparation for Activity Records events, including truncation of oversized data before it is stored.
- AUDIENCE_DEVELOPER: Experimental Activity Records outbox store with a migration entry point, and a new activity-records extra that installs the database dependency.
- AUDIENCE_DEVELOPER: Experimental Activity Records outbox relay with an enqueue function that records events without blocking the caller, and Prometheus metrics for the outbox.
- AUDIENCE_DEVELOPER: Gemini 4 Hydrogen is available in the language model registry as `litellm:gemini-4-hydrogen` and `litellm:vertex-gemini-4-hydrogen`. Reasoning effort defaults to `medium`; `xhigh` is not supported yet.
- AUDIENCE_DEVELOPER: Experimental RabbitMQ sender for the Activity Records outbox, configured with `AMQP_URL`, or `AMQP_HOST` with `AMQP_USERNAME` and `AMQP_PASSWORD`, plus a logging sender for testing. The new `activity-records-amqp` extra installs aio-pika. The sender declares the ingest queue and its dead letter queue like the Node services, so a publish to the default exchange does not fail as unroutable before the consumer has started.
- AUDIENCE_DEVELOPER: Toolkit and Orchestrator know GPT 6.2 Astra and GPT 6.2 Sol on Azure and LiteLLM. Requests to these models leave out temperature, top_p, logprobs and top_logprobs, which the GPT 6.2 API rejects.
#### Fixed
- AUDIENCE_ADMIN: The default Code Execution (`code_interpreter`) system prompts now include PDF layout rules (reportlab Platypus flowables so text wraps, no `canvas.drawString` or `Preformatted` for running text, Markdown turned into formatting, a DejaVu TrueType font, and a `pdfplumber` check that no word lies past the page width), so generated PDFs keep every word on the page. Spaces that store their own `toolDescriptionForSystemPrompt` keep their text until it is updated or reset to the default.
- AUDIENCE_USER: The hallucination check now finds every source the chat shows as cited, including `[source 7]`, `[source_7]`, `[7]`, `[source: 1, 2]` and bold `[**7**]` citations. Before, it only matched `[sourceN]`, so answers using other forms gave the judge no context and were scored high risk. Custom `reference_pattern` settings keep working, and a warning is logged when sources exist but none are cited.
#### Security
- AUDIENCE_DEVELOPER: Toolkit raises its minimum Pillow dependency to a release that patches published vulnerabilities.

### uqadm
#### Added
- AUDIENCE_ADMIN: `uqadm space upsert` and `uqadm space migrate` take `--no-access` to update a space without adding the source's access entries, so the destination keeps its access rights, and `--with-mcp-servers` to also copy MCP server bindings (skipped when migrating between environments). `uqadm space export --no-access` leaves access entries out of the snapshot, `uqadm space diff --ignore-access` compares spaces without them, and `uqadm kb sync --no-inherit-access` creates new folders without inheriting parent access. Both commands now warn that scope rules are never copied. A destination slot without `UNIQUE_API_BASE` no longer inherits the source slot's API base during `migrate`.
- AUDIENCE_ADMIN: `uqadm kb sync --skip-ingestion` stores files as uploaded, without ingesting them. Use it for code and skills, which are read as files and not searched. Without it, a file with little readable text (an HTML page, for example) can end as `FAILED_TOO_LESS_CONTENT` and can no longer be downloaded.
#### Fixed
- AUDIENCE_ADMIN: `uqadm kb rm --recursive` now removes the whole tree. It deletes each folder's files, then its subfolders, then the folder. Before, it could report success for a folder that still held files or subfolders. It now prints each deleted file and folder with a final count, keeps the parents of anything it could not delete, and exits non-zero in that case.

### Web Search

- AUDIENCE_ADMIN: Activity Records for web search record one entry per outgoing query, plus one per tool call blocked or failed before any query was sent. Each entry includes the user prompt and the tool arguments. Disabled by default; recording requires `FEATURE_FLAG_ENABLE_WEB_SEARCH_ACTIVITY_RECORDS_UN_28965` and `FEATURE_FLAG_ENABLE_ACTIVITY_RECORDS_EVENTS_UN_22616` for the company, and an active Activity Records outbox in the host service.
#### Changed
- AUDIENCE_USER: Google search result snippets now include additional metadata.
#### Fixed
- AUDIENCE_ADMIN: The web search Activity Records flag is now evaluated per user as well as per company, and tool calls while no outbox is running are counted.
