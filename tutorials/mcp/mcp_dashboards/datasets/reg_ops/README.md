# reg_ops

Regulatory & Operations Agent dashboard for the Millennium demo. Combines
**regulatory intelligence** (policy impact from regulator notifications) with
**third-party risk** (vendor contracts that need renegotiation when policies
move).

Process docs — how the agent works, what the dashboard surfaces, and the open
demo issues — live in [`docs/`](./docs/README.md). Distilled from a walkthrough
of the current HTML demo.

```text
docs/                 # Reg Ops processes (visual, Mermaid) — start at docs/README.md
```

This dataset folder is docs-first today; contract / FastMCP / Astro scaffolding
can follow the same layout as [`account_review`](../account_review/README.md)
when we implement it.
